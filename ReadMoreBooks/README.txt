ReadMore Books - Entity Framework Core Task

Requirements covered:
1. Console Application using Entity Framework Core
2. EF Core conventions only
3. SQL Server provider
4. Entities: Book, Author, Category
5. ApplicationDbContext
6. Database creation demonstrated with EnsureCreated()

How to run:
1. Open ReadMoreBooks.csproj in Visual Studio.
2. Make sure SQL Server LocalDB is installed/running.
3. Restore NuGet packages.
4. Run the project.
5. The console should display:
   Database created successfully!

Database name:
ReadMoreBooksDb

Note:
The project intentionally does not use Data Annotations, Fluent API, or OnModelCreating configuration.
